# 🏂 It's All in the Hips

**Bomb the hill. Hit the line. Try not to eat shit.**

*It's all in the hips.*

A stupidly simple, tilt-controlled snowboarding game built for mobile browsers.

Tilt your phone to carve your rider down the mountain, hit the targets, build your flow, and see how long you can keep the run alive.

## 🎮 The Idea

Remember those old LCD driving games where you basically just moved left and right to avoid things?

Yeah. That — but snowboarding.

The goal is to keep the controls ridiculously simple:

**Tilt left. Tilt right. That's it.**

The game handles the cool stuff. You just find the line.

## 🏔️ Current Status

**v0.1 — Prototype**

We're currently testing the core mechanic:

* 📱 Phone tilt controls
* 🏂 Smooth carving
* 🎯 Target / gate system
* 🔥 Flow multiplier
* ⚡ Increasing speed
* ⌨️ Keyboard controls for desktop testing
* 📐 Tilt calibration

Right now, we're answering one question:

**Is this stupidly simple enough to be stupidly addictive?**

## 🚧 What's Next

If the core mechanic feels good:

Snowboarder → actual mountain terrain → gates → obstacles → jumps → tricks → better physics → haptics → sound → increasingly ridiculous runs.

No complicated button combinations.

No learning 47 different tricks.

Just hit the right line and let the game make you look awesome.

## 🛠️ Built With

HTML, CSS, and JavaScript.

Designed to run directly in a modern mobile browser with device-orientation controls.
